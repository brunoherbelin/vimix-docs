## What it does

This page is a model for contributors. It shows where the title, the description, the step-by-step instructions and the specific information go.
Replace it with a real feature page once the first contribution is merged.

## How to

1. Copy the [_template folder](https://github.com/brunoherbelin/vimix-docs/tree/main/_template) and rename it after your feature.
2. Add annotated screenshots in `img/` and reference them with an alt text in `index.md`.
3. Open a pull request.
