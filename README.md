# vimix documentation

Community-written documentation for [vimix](https://github.com/brunoherbelin/vimix), the video live mixer.

Each page describes one feature: what it does, how to use it (with annotated screenshots), and specific information.

## Contribute in 5 steps

1. Fork this repository.
2. Copy the `_template/` folder to `pages/<category>/<feature-name>/`.
3. Take screenshots in vimix and add arrows and text with the **Annotation** feature. Export them as PNG into the `img/` folder.
4. Edit `index.md`: fill in the front matter and the three sections.
5. Open a pull request.

No git knowledge needed: everything can be done from the GitHub web interface.
See [CONTRIBUTING.md](CONTRIBUTING.md) for details, and
[the example page](pages/getting-started/example-feature/index.md) for a model.

Cannot make a pull request? Open an issue with the *Documentation proposal* form and attach your text and images.
